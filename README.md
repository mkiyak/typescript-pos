# typescript-pos

A single, stateless, async TypeScript interface to Turkish bank virtual POS (sanal POS) gateways, including 3D Secure flows. Node.js 20 or newer.

> Status: early development. Nothing is published yet.

## Status

| Gateway                                                                                                | Banks                                                                                       | Status          |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- | --------------- |
| `AssecoPos`                                                                                            | İş Bankası, Ziraat (Asseco), Akbank (Asseco), Halkbank, TEB, Şekerbank, Finansbank (Asseco) | planned (v0.1)  |
| `PayFlexV4Pos`                                                                                         | VakıfBank, Ziraat (PayFlex)                                                                 | planned (v0.1)  |
| `PayFlexCPV4Pos`                                                                                       | VakıfBank common payment                                                                    | planned (v0.2)  |
| Garanti, Akbank (new API), PosNet, PayFor, InterPos, Kuveyt, VakıfKatılım, Param, Tosla, PayTR, Iyzico |                                                                                             | planned (v0.3+) |

## Install

```sh
npm install typescript-pos
```

Usage documentation will be added with the first release.
